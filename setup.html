Make checkout real

Where the Stripe links come from

You do not invent a link. Stripe gives it to you. The faster path is one secret key. The click path is a payment link per product.

Fast path

One secret key

The shop creates the Stripe checkout itself. You do not make a payment link for each item.

  1. Open dashboard.stripe.com and turn on Test mode.
  2. Developers → API keys.
  3. Copy the Secret key. It starts with sk_test_.
  4. In Vercel, add STRIPE_SECRET_KEY and redeploy.
Click path

Payment links

Use this if you do not want a secret key in Vercel.

  1. Stripe Dashboard → Product catalog → Add product.
  2. Set the name and price, then save.
  3. Open the product → Payment links → New, or Payment links in the left menu.
  4. Copy the URL. It looks like https://buy.stripe.com/test_...
  5. Paste it into PRODUCT_1_LINK, PRODUCT_2_LINK, PRODUCT_3_LINK, STRIPE_MEMBER_LINK, or STRIPE_OPERATOR_LINK.
